# FuseForge positioning

FuseForge is a thin coordinator that lets a developer describe one full-stack
feature once while Compforge and OOPforge retain their specialist ownership.

## Category

- full-stack development coordinator;
- methodology-pack orchestration;
- shared-contract and integrated-checkpoint policy.

## Ownership boundary

- FuseForge owns cross-stack semantics, workspace coordination, delegation
  validation, stage barriers, and user-facing integrated approval.
- Compforge owns TypeScript and React frontend discipline.
- OOPforge owns Java Spring and Python FastAPI backend OOP/DDD discipline.

FuseForge does not duplicate specialist methodology or provide a general
multi-agent runtime.

## Current evidence

The experimental coordinator implements four approved slices covering
selection, specialist bootstrap, greenfield workspace setup, and Design
integration policy. See [support scope](../reference/support-scope.md) and
[coordinator Test evidence](../verification/coordinator-test-2026-08-27.md).

Calendar application source and connected client-to-backend evidence have not
been created.
